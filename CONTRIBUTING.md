# Contributing

Thank you for your interest in contributing to the Nextcloud MCP Gateway!

## Development Setup

1. Make sure you have Go 1.22+ installed.
2. Clone this repository.
3. Use `make build` to build the binary.
4. Run tests with `make test` or `make coverage`.

## Guidelines

- Follow standard Go formatting and idioms (`gofmt`, `go vet`).
- Write unit tests for new features.
- Adhere to the Conventional Commits specification for commit messages.
- Ensure all CI checks pass before requesting a review.
